## 1. Why (问题与证据)

* **硬件真相：** RDNA1 原生 Wave32，Wave64=2×Wave32 发射；`EXEC==0` 半波可 skip 但写 SGPR/VCC 的 VALU 永不 skip；`IB_STS` 四计数器中 `VM_CNT/VS_CNT/LGKM_CNT` 需 `S_WAITCNT` 显式等待。`VGPR` 按 8(Wave32)/4(Wave64) Dword 组分配，SGPR 固定 106+2+16，`VOP3P` 支持 2×f16 打包，`DPP16` 限 16 lane。
* **本引擎现状：** `arena.rs` 4 原子管线 `dissolve(W=2)/imagedissolve(W=3)/alpha_mask(W=2)/mask(W=2)` 各占 `WgslShaderCache` 一 key；FS 体为 `mix/sample` 直列，无 uniform 级早退，`imagedissolve` 的 `channel` 分支在采样后，`alpha_mask/mask` 临时 `vec4` 驻留过长。`the_question` 全屏转场帧是唯一种会同时触发 2-3 采样+`mix` 的重型 FS，prefs 页 `~120 presents/s` 已由 `ring256+BgCache` 缓解，但管线切仍碎。
* **机会：** uniform 级 `amount==0/1` 与 `channel` 为同波 32 lane 同值，最贴 `S_CBRANCH_EXECZ` 全波跳；`offset/mult` 的 `clamp((ctrl+off)*mult)` 可全量 SALU 标量化；临时 VGPR 收敛可把峰值 8→5，提升 `waves/CU` 从 8→16。

## 2. Goal / Non-goals

**Goal:**
* 在 `A` 边界内完成 A2-U 4 段 WGSL 的 SALU 提升+EXEC 早退+VGPR 收敛，BC-160 1080p 转场帧 p95↓≥10%，像素零回归。

**Non-goals:**
* 不合并 4 管线为 uber（A2-M defer）、不做 LDS 缓存或 VOP3P 打包（A2-V defer）、不引 Vulkan 显式 subgroup、不改 `draw.py` 批逻辑与 `blur/Live2D`

## 3. Fixed Contract (不可漂)

* `WgpuDraw` 单渲染器、`SWAPCHAIN_FORMAT=Rgba8Unorm+PMA`、host 分支 `if getattr(renpy,"host_build",False)` 不破 SDL 树
* `shaders.py:register_wgsl_shader` 的 4 part 契约：`tex_count∈{2,3}`, `uniform_layout="params16"`, `composition_only=False`, `atomic=True`
* `composer.py:WgslShaderCache` 以排序 part 集 `sha1[:16]` 为 `cache_key = composed:<hex>`，`tex_count/layout/has_uniforms` 仍由 Rust SSOT 校验
* `arena.rs:build_bind_group_layout` 的 `uniform_binding(tex_count)` 与 WGSL `group(0)@binding` 布局不动
* `ldd host/target/release/renpy-host | grep -iE 'libSDL'` 为空；`RUST_LOG=info` 含 `backend=Vulkan`

## 4. Design (D1-D6 锁定版)

### D1 Ownership
`shader.rs:emit_wgsl` 为 WGSL 文本真源；`arena.rs:{DISSOLVE,IMAGEDISSOLVE,ALPHA_MASK,MASK}_WGSL` 为管线工厂；`shaders.py:_PIPELINE_KEYS` 为诚实门；`composer.py` key 不变。

### D2 Component — 4 段 WGSL 改动（文本级 diff）
* **DISSOLVE_WGSL** — 前置 `let amt = clamp(u.data0.x,0,1); if (amt <= 0.0) { color = textureSample(tex1,...)*v.color; PMA; return; } if (amt >= 1.0) { color = textureSample(tex0,...)*v.color; PMA; return; }`，中间 `mix` 路径 `let c0=textureSample(tex0...); let c1=textureSample(tex1...); color = mix(c1,c0,amt)*v.color`，复用 `amt`，去重 `clamp`。
* **IMAGEDISSOLVE_WGSL** — `let off=u.data0.x; let m=u.data0.y; let ch=u.data0.z; let ctrl = select(textureSample(tex0...).r, textureSample(tex0...).a, ch>0.5); let a = clamp((ctrl+off)*m,0,1); let btm=textureSample(tex1...); let top=textureSample(tex2...); color = mix(btm,top,a)*v.color`；采样后立即算 `a`，`ctrl` VGPR 不跨采样存活。
* **ALPHA_MASK_WGSL** — `let s=textureSample(tex0...); let ma=textureSample(tex1...).a; color = vec4(s.rgb*ma, s.a*ma)*v.color` 改 `let s/...`→`let ma`→`color=vec4(s.rgb*ma,...)` 不引入中间 `vec4 mask`。
* **MASK_WGSL** — `let mult=u.data0.x; let off=u.data0.y; let s=...; let ma=textureSample(tex1...).a; let k = ma*mult+off; color = vec4(s.rgb*k, s.a)*v.color`，`k` 复用。
* 统一：临时名收敛 `s/ma/a/k/amt`，live range ≤3 VGPR，inline 常量 `0.0/1.0` 保留 free。

### D3 Data flow & EXEC
uniform 级分支（同波 32 lane 同值）→ `EXEC` 全活/全跳，最贴 `S_CBRANCH_EXECZ`；`channel` 分支同理，无波内分歧。

### D4 Error & Fallback
* WGSL 语法经 `validate_wgsl_with_naga`（naga front+validator），`hard_fail=True` 时抛 `ComposerError`，否则 soft-fail 回退
* 性能回退：`host/scripts/benchmark_bc160.sh` 1800 帧 p95 未降或 `cargo check`/`pytest` 失败 → 单文件回滚 4 串文本

### D5 Compat
不新增 owner/artifact/workflow step；`WgslShaderCache` key 熵不变；`_PIPELINE_KEYS` 诚实门 `assert_pipeline_map_honest()` 仍过。

### D6 Verification
* `cargo check -p renpy-host` + `python -m pytest tests/test_wgpu_composer.py -v`
* `bash host/scripts/phase9_gates.sh` G01-G08 `MAE≤2/255`
* `RENPY_HOST_BENCHMARK_FRAMES=1800 cargo run -p renpy-host -- the_question --benchmark` 对比基线 p50/p95
* `RUST_LOG=info` 验 `backend=Vulkan`；可选 RGP 看 `VGPR`/`waves/CU`/`VM_CNT` 等待

## 5. Alternatives Considered

* **A2-M uber 合批** — 已评估 defer：虽省 4→1 key 但引入波内 `switch(mode)` 分歧，且 VN 场景单帧多模混用少，收益需证据；待 A2-U 达标且 `benchmark_bc160.sh` 证明管线切为主因再启。
* **A2-V VGPR定量+LDS** — defer：需 RGP 真 `VGPR_ALLOC` 计数，当前无 evidence 属过度承诺。

## 7. Risks & Mitigations

* 分支不当致抖动 → 基准 1800 帧 3 次取中位，抖动>5% 即回退分支写法
* `channel` 为红/alpha 双 alias 的 product 逻辑（`doc/wgsl_shader_migration.md`）混淆 → 在 `shaders.py` 注释 `data0.z channel` 语义并加 `composer` 断言
* 无 RGP 时无法定量 VGPR → 用 naga 估算 live range + `benchmark` 间接证伪
